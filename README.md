# 🛒 Retail Consumer Behavior Analytics
### End-to-End Data Pipeline: Python ➔ MySQL ➔ Power BI

---

## 📌 Business Overview
A leading retail company wanted to understand shifting **customer shopping behavior** across different demographics and sales channels (Online vs. Offline)[cite: 2, 3]. The goal was to identify how factors like **discounts, reviews, and seasonality** drive consumer decisions and repeat purchases[cite: 4].

This project provides actionable insights to:
* Identify emerging **consumer trends**[cite: 6].
* Improve **customer engagement** and loyalty[cite: 6].
* Optimize **marketing and product strategies**[cite: 6].

* **Data Modeling & Analysis:** MySQL [cite: 9]
* **Business Intelligence:** Power BI [cite: 10]
* **Version Control:** Git & GitHub [cite: 13]

## 🚀 Project Workflow

### 1️⃣ Phase 1: Data Cleaning (Python)
Using **Pandas**, I transformed the raw dataset into an analysis-ready format[cite: 8].
* Handled **missing values** and data inconsistencies.
* Performed **Feature Engineering** to categorize customers by demographics and shopping frequency.
* Exported cleaned data as `cleaned_customer_data.csv`.

### 2️⃣ Phase 2: Database Management (SQL)
Structured the data in **MySQL** to simulate real-world business transactions[cite: 9].
* Designed relational tables to organize customer segments and loyalty data[cite: 9].
* Developed complex queries to extract insights on **purchase drivers** and **sales channel performance**[cite: 9].

### 3️⃣ Phase 3: Interactive Dashboard (Power BI)
Built a dynamic dashboard to visually communicate key findings to stakeholders[cite: 10, 12].
* **KPI Tracking:** Sales, Average Order Value (AOV), and Retention Rate.
* **Trend Analysis:** Impact of discounts and reviews on shopping decisions[cite: 4, 10].
* **Channel Comparison:** Visualizing Online vs. Offline shopping patterns[cite: 3, 10].
