# 🛒 Retail Consumer Behavior Analytics
### End-to-End Data Pipeline: Python ➔ MySQL ➔ Power BI

---

## 📌 Business Overview
A leading retail company wanted to understand shifting **customer shopping behavior** across different demographics and sales channels (Online vs. Offline). The goal was to identify how factors like **discounts, reviews, and seasonality** drive consumer decisions and repeat purchases.

This project provides actionable insights to:
* Identify emerging **consumer trends**.
* Improve **customer engagement** and loyalty.
* Optimize **marketing and product strategies**.

---

## 🛠️ Tech Stack & Skills
* **Data Preparation:** Python (`Pandas`, `NumPy`) 
* **Data Modeling & Analysis:** MySQL
* **Business Intelligence:** Power BI 
* **Version Control:** Git & GitHub

---

## 🚀 Project Workflow

### 1️⃣ Phase 1: Data Cleaning (Python)
Using **Pandas**, I transformed the raw dataset into an analysis-ready format.
* Handled **missing values** and data inconsistencies.
* Performed **Feature Engineering** to categorize customers by demographics and shopping frequency.
* Exported cleaned data as `cleaned_customer_data.csv`.

### 2️⃣ Phase 2: Database Management (SQL)
Structured the data in **MySQL** to simulate real-world business transactions.
* Designed relational tables to organize customer segments and loyalty data.
* Developed complex queries to extract insights on **purchase drivers** and **sales channel performance**.

### 3️⃣ Phase 3: Interactive Dashboard (Power BI)
Built a dynamic dashboard to visually communicate key findings to stakeholders.
* **KPI Tracking:** Sales, Average Order Value (AOV), and Retention Rate.
* **Trend Analysis:** Impact of discounts and reviews on shopping decisions.
* **Channel Comparison:** Visualizing Online vs. Offline shopping patterns.
